# Videre — see the scam before you sign

Videre checks crypto tokens, wallets and links for scams before you touch them:
honeypots, rug pulls, insider clusters, fake tokens and phishing sites.

**What it does**
- Token check on Ethereum, BSC, Base and other EVM chains, plus Solana (basic support)
- Wallet check: who funded it, links to known scams and insider clusters
- Link check: phishing and lookalike domains
- Plain verdicts: AVOID / WATCH / OK, with evidence for every flag
- Calls out when other scam checkers get it wrong, shown in red

**How we work**
- Read-only: never asks for wallets, keys or signatures
- Hard verdicts only with on-chain evidence; unverified tokens never get a green
- Open benchmark: 0 of 118 scams marked safe on unseen test sets
